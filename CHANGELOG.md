## [1.0.0] - 2025-04-08

### Added
- Initial repository setup for "Introduction to GitHub" exercise
- Step-by-step guides for learning GitHub fundamentals:
  - Step 1: Create a branch
  - Step 2: Commit a file
  - Step 3: Open a pull request
  - Step 4: Merge your pull request
- GitHub Actions workflows for automated exercise validation:
  - Workflow for branch creation validation
  - Workflow for commit validation
  - Workflow for pull request validation
  - Workflow for merge validation
- README with comprehensive exercise instructions
- Profile README exercise to help users learn Markdown
- MIT License and Code of Conduct
- Status badges for workflow monitoring

### Documentation
- Added detailed step-by-step instructions in `.github/steps/` directory
- Included video resources and GitHub Docs links for learning
- Added troubleshooting guides for common issues
